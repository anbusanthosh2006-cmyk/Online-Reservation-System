# Online Reservation System

A Java-based Online Reservation System developed using **Java Swing, JDBC, and SQLite**.

## 📌 Project Description

This project provides a simple desktop application for managing online reservations. Users can log in, make reservations, view booking history, and cancel reservations.

## 🚀 Features

- User Login
- Make Reservations
- View Booking History
- Cancel Reservations
- SQLite Database Integration
- Java Swing GUI
- JDBC Database Connectivity

## 🛠️ Technologies Used

- Java
- Java Swing
- JDBC
- SQLite
- Eclipse IDE
- Git & GitHub
